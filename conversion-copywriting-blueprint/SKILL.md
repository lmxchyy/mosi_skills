# Conversion Copywriting Blueprint

Use this skill to move from product description to problem solving, desire building, and decisive action. Prioritize conversion clarity over cleverness.

## Core Workflow

1. Identify the buyer, product, offer, channel, and desired action. If details are missing, make reasonable assumptions and state them briefly.
2. Extract the user's urgent pain, desired identity shift, main objection, proof assets, and urgency lever.
3. Draft with the three-part structure: Hook -> Bridge -> CTA.
4. Tighten the copy by replacing feature claims with outcome language, concrete scenes, and one clear next step.
5. Provide variants when useful: direct pain-led, aspiration-led, proof-led, and urgency-led.

## Psychological Anchors

### Pain Amplification

Do not merely name the problem. Show the uncomfortable everyday moment where the problem becomes costly, tiring, embarrassing, or frustrating.

Use prompts like:

- "你是否经常...？是不是感觉很累？"
- "还在为了...反复消耗时间和情绪？"
- "每次...，是不是都让你觉得自己又慢了一步？"

Keep pain amplification specific, believable, and proportional. Avoid inventing fear claims that the product cannot responsibly solve.

### Aspiration Painting

Translate product features into identity upgrades or state changes. Sell the better version of the user, not the object.

Use prompts like:

- "想象一下...你将拥有..."
- "从...变成..."
- "不再只是...，而是..."

Convert features into outcomes:

- Feature: "自动生成报告"
- Outcome: "周一早上不用再临时补数据，打开电脑就能直接汇报"
- Identity shift: "从被任务追着跑的人，变成节奏清晰的掌控者"

### Scarcity And Urgency

Create a clear reason to act now: limited seats, limited stock, bonus deadline, launch price, or expiring consultation window.

Use urgency only when it is true or framed as an offer constraint. Prefer one urgency lever per CTA.

### Social Proof And Authority

Reduce perceived risk with numbers, user groups, rankings, expert endorsement, testimonials, case results, media mentions, or usage signals.

Use concrete proof when available. If proof is missing, use softer credibility language such as "适合..." or "为...场景设计", and avoid fake metrics.

## Copy Structure

### Hook

Goal: stop the scroll within 3 seconds.

Write one sharp opening sentence that hits the most painful moment, surprising belief, or desired transformation.

Self-check:

- Is the opening visually or emotionally "刺眼" enough?
- Would the target buyer feel "this is about me" immediately?
- Does it avoid generic claims like "高品质好物" or "提升效率神器"?

### Bridge

Goal: connect pain to value.

Use this sequence:

1. Painful current state
2. Ideal future state
3. Product or offer as the bridge

Show the before/after contrast in plain language. Make the value obvious before asking for action.

### CTA

Goal: make the next step simple and tempting.

Use one action only: buy now, book a call, claim the trial, join the list, download the guide, or message a keyword.

Pair the action with one incentive or urgency lever:

- "今晚 24:00 前下单，解锁..."
- "点击领取..."
- "回复关键词..."
- "现在预约，保留..."

## Optimization Checklist

- Keywords: extract 3 result-oriented adjectives, such as efficient, elegant, worry-free, calm, confident, faster, clearer.
- Scene: add a concrete time, place, or routine moment, such as "周一早晨通勤时" or "周末窝在沙发上放松时".
- Benefits: split each benefit into emotional gain plus saved time, money, effort, or risk.
- One reader: write to one concrete buyer segment, not a vague public audience.
- One promise: make the core promise memorable and repeat it through the bridge and CTA.
- One action: remove competing CTAs.

## Output Format

When drafting from scratch, prefer:

```markdown
## 假设
[brief assumptions if needed]

## 关键词
[3 result-oriented words]

## 文案
[Hook]

[Bridge]

[CTA]

## 备选钩子
1. ...
2. ...
3. ...
```

When reviewing existing copy, lead with the biggest conversion blockers, then provide a rewritten version.

Use Chinese when the user's source or market is Chinese; otherwise match the user's language.
